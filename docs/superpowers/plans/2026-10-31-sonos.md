# Contrôle Sonos depuis la notch — plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal :** quand Spotify joue sur une Sonos, une ligne dans le lecteur de la notch permet de régler le volume, déplacer/grouper les pièces, utiliser des favoris et revenir au dernier groupe ; les touches volume du Mac règlent alors la Sonos.

**Architecture :** code dans `boringNotch/modules/Sonos/` (dossier synchronisé par Xcode, pas d'édition du `.pbxproj`). Une couche pure (parsing XML, SOAP, logique de groupes) testée par un auto-test `swiftc` ; un client SOAP UPnP local (port 1400) ; un `SonosStore` `@MainActor` qui découvre les Sonos (Bonjour), interroge Spotify par AppleScript et publie l'état ; une vue insérée dans `MusicControlsView` ; un aiguillage dans `MediaKeyInterceptor`.

**Tech Stack :** Swift / SwiftUI macOS, `Network` (`NWBrowser`), `URLSession`, `XMLParser`, `Defaults`, `AppleScriptHelper` existant.

**Spec :** `docs/superpowers/specs/2026-10-31-sonos-design.md`

## Global Constraints

- Local uniquement : aucun Home Assistant, API cloud Sonos, Spotify Web API ou compte.
- Aucune nouvelle dépendance (SPM ou autre).
- Hors réseau / Sonos injoignables : la ligne Sonos est absente, **aucune** alerte ni message d'erreur.
- Les touches volume ne règlent la Sonos **que** si Spotify joue sur une Sonos ; sinon, comportement actuel inchangé.
- Volume principal = `GroupRenderingControl#SetGroupVolume` sur le coordinateur (pas l'AppleScript Spotify).
- Détection indépendante de `Defaults[.mediaController]` : le module interroge Spotify lui-même.
- Favoris et dernier groupe identifiés par UUID de pièce (`RINCON_…`), jamais par nom.
- Déplacement : une coupure de 1–2 s est acceptée ; la lecture doit reprendre seule dans la nouvelle pièce au même endroit. Pas de repli « muter l'ancienne pièce ».
- Le dépôt contient des modifications non commitées dans `modules/Agents/` : chaque commit ajoute **uniquement** les chemins de la tâche (`git add <chemins>`, jamais `git add -A`).

## Review Focus

1. **Spotify en pause sur Sonos** : la ligne doit rester visible (on règle encore le volume) tant que le groupe Sonos a le morceau Spotify chargé ; elle disparaît quand Spotify joue en local ou est fermé. → test `activeGroup` avec `transportState == "PAUSED_PLAYBACK"` (Tâche 1).
2. **Titres avec accents / « - Remastered » / feat.** : la correspondance Sonos ↔ Spotify ne doit pas échouer sur casse, accents ou suffixes. → test `tracksMatch` (Tâche 1).
3. **Retirer la dernière pièce cochée** : décocher la seule pièce qui joue ne doit rien faire (sinon la musique s'arrête sans moyen de revenir). → test `toggled` (Tâche 1).
4. **Favori contenant une pièce disparue** (débranchée) : appliquer le favori utilise les pièces présentes, ignore les absentes ; si aucune n'est présente, ne fait rien. → test `plan(for:)` (Tâche 1).
5. **Touche volume avec Sonos lent / injoignable** : la touche ne doit pas bloquer l'event tap ni retomber sur le volume du Mac ; l'appel réseau part en `Task`, l'event est consommé. → vérif. manuelle (Tâche 5).

```swift
struct SonosRoom: Codable, Hashable, Identifiable { let id: String /* RINCON_… */; let name: String; let host: String /* "192.168.1.20" */ }
struct SonosGroup: Hashable { let coordinatorID: String; let memberIDs: [String] }
struct SonosFavorite: Codable, Hashable, Identifiable { var id: UUID; var name: String; var roomIDs: [String] }
struct SonosTrack: Equatable { let title: String; let artist: String }

enum SonosParse {
    static func topology(_ xml: String) -> (rooms: [SonosRoom], groups: [SonosGroup])   // GetZoneGroupState (ZoneGroupState déséchappé), ignore Invisible="1"
    static func value(_ tag: String, in soapResponse: String) -> String?               // ex. "CurrentTransportState", "CurrentVolume"
    static func track(fromDIDL didl: String) -> SonosTrack?                              // dc:title, dc:creator du TrackMetaData
}
enum SonosSOAP { static func envelope(service: String, action: String, args: [(String, String)]) -> String }

enum SonosLogic {
    static func tracksMatch(_ a: SonosTrack, _ b: SonosTrack) -> Bool
    static func toggled(_ group: SonosGroup, room: String) -> [String]?        // nouveaux membres, nil si refus (dernière pièce)
    static func plan(for target: [String], available: Set<String>) -> [String]? // membres cibles présents, nil si vide
    static func updatedHistory(previous: [String]?, old: [String], new: [String]) -> [String]? // « Revenir à »
    static func label(for group: SonosGroup, rooms: [SonosRoom]) -> String      // "Cuisine" / "Cuisine + Bureau"
}
```

```swift
struct SonosClient {   // timeout 2 s, POST http://<host>:1400/<controlURL>, header SOAPACTION "urn:…:<Service>:1#<Action>"
    func topology(host: String) async throws -> (rooms: [SonosRoom], groups: [SonosGroup])
    func transportState(host: String) async throws -> String           // "PLAYING" | "PAUSED_PLAYBACK" | "STOPPED" | …
    func currentTrack(host: String) async throws -> SonosTrack?
    func volume(host: String) async throws -> Int
    func setVolume(host: String, _ v: Int) async throws
    func groupVolume(coordinator host: String) async throws -> Int
    func setGroupVolume(coordinator host: String, _ v: Int) async throws
    func groupMute(coordinator host: String) async throws -> Bool
    func setGroupMute(coordinator host: String, _ m: Bool) async throws
    func join(host: String, coordinatorID: String) async throws        // SetAVTransportURI x-rincon:<id>
    func leave(host: String) async throws                              // BecomeCoordinatorOfStandaloneGroup
    func delegate(coordinator host: String, to newID: String) async throws // DelegateGroupCoordinationTo, RejoinGroup=1
}
final class SonosDiscovery { func firstHost() async -> String? }       // NWBrowser _sonos._tcp → résout une IPv4 ; nil après 3 s
```

### Task 3 : `SonosStore` (état, détection Spotify, actions, réglages)

**Files :**
- Create : `boringNotch/modules/Sonos/SonosStore.swift`
- Modify : `boringNotch/models/Constants.swift` (clés `Defaults`)
- Modify : `boringNotch/boringNotchApp.swift:283` (démarrage : `SonosStore.shared.start()` à côté de `NotchModules.startAll()`)

**Interfaces :**
- Consumes : Tâches 1–2 ; `AppleScriptHelper.execute(_:)`.
- Produces :
```swift
// Constants.swift
static let enableSonos = Key<Bool>("enableSonos", default: true)
static let sonosFavorites = Key<[SonosFavorite]>("sonosFavorites", default: [])
static let sonosLastGroup = Key<[String]?>("sonosLastGroup", default: nil)

@MainActor final class SonosStore: ObservableObject {
    static let shared: SonosStore
    @Published private(set) var rooms: [SonosRoom]
    @Published private(set) var activeGroup: SonosGroup?          // nil ⇒ ligne masquée, touches → Mac
    @Published private(set) var groupVolume: Int                  // 0–100
    @Published private(set) var roomVolumes: [String: Int]        // seulement membres du groupe actif
    var isActive: Bool { activeGroup != nil }
    var label: String                                             // SonosLogic.label
    func start()
    func move(to roomID: String) async                            // la musique ne joue plus que là
    func toggle(_ roomID: String) async                           // via SonosLogic.toggled
    func apply(_ roomIDs: [String]) async                         // favori ou « Revenir à », via SonosLogic.plan
    func setGroupVolume(_ v: Int) async
    func adjustGroupVolume(by delta: Int) async                   // touches ; borne 0–100
    func setRoomVolume(_ roomID: String, _ v: Int) async
    func toggleMute() async
    func saveFavorite(name: String)                               // groupe actif → Defaults[.sonosFavorites]
    func deleteFavorite(_ id: UUID)
}
```

- Polling toutes les **3 s** tant que `Defaults[.enableSonos]` est vrai **et** que Spotify est lancé (sinon `activeGroup = nil`, pas d'appel réseau). AppleScript : `if application "Spotify" is running then tell application "Spotify" to return (player state as string) & "\n" & name of current track & "\n" & artist of current track`.
- Pièce active : groupe dont le coordinateur a `transportState` ∈ {`PLAYING`, `PAUSED_PLAYBACK`} et `tracksMatch` avec Spotify (Review Focus 1, 2).
- Hôte : `SonosDiscovery.firstHost()` une fois, puis les hôtes de `topology` ; si l'hôte ne répond plus, redécouvrir. Toute erreur réseau ⇒ `activeGroup = nil`, silencieusement.
- `move(to:)` : si la cible est déjà le seul membre → rien ; `join(target, coordinator)` → `delegate(coordinator, to: target)` → `leave` pour chaque autre ancien membre ; puis rafraîchir.
- `apply` : le premier membre de `plan` devient coordinateur (comme `move`), puis `join` des autres, `leave` des membres hors liste.
- Chaque changement de membres passe par `SonosLogic.updatedHistory` → `Defaults[.sonosLastGroup]`, y compris quand le changement est observé au polling (fait depuis l'app Sonos).
